# Создание приложения «ВАЛЕРА» для macOS

На Mac скачайте этот репозиторий, откройте Terminal в его папке и выполните:

```bash
bash build_valera_app.sh
```

Скрипт создаст рядом приложение `ВАЛЕРА.app`. Откройте его двойным щелчком — появится окно с текстом «ВАЛЕРА 1 15».

Можно указать другой путь для приложения:

```bash
bash build_valera_app.sh "$HOME/Desktop/ВАЛЕРА.app"
```
